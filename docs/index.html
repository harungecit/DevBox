Your whole local dev stack, one click away.

Tüm yerel geliştirme ortamın, tek tıkla hazır.

DevBox; Go, Node.js, PHP, Python ve Rust'ı — yanında Nginx, PostgreSQL, MySQL, MariaDB, MongoDB, Redis ve Mailpit'i — kurar ve çalıştırır, her projeye SSL'li bir .test alan adı verir ve Cloudflare üzerinden dünyaya açar. Docker yok, PATH ile uğraşmak yok, vakit kaybı yok.

.test domains & SSL

.test alan adları & SSL

Add a project folder and get https://myapp.test with a trusted local certificate. The built-in front-door terminates HTTPS and routes every domain to the right backend — nginx, Apache, Caddy, FrankenPHP or your dev server — and shows a friendly page when that backend is stopped.

Bir proje klasörü ekleyin, güvenilir yerel sertifikalı https://myapp.test hazır. Yerleşik ön kapı HTTPS'i sonlandırır ve her alan adını doğru arka uca yönlendirir — nginx, Apache, Caddy, FrankenPHP veya kendi dev sunucunuz; arka uç kapalıysa anlaşılır bir sayfa gösterir.

Install in a minute

Bir dakikada kur

Windows 10 or 11, 64-bit. WebView2 is installed automatically if missing.

Windows 10 veya 11, 64-bit. WebView2 eksikse otomatik kurulur.

Download the installer

Kurulum dosyasını indir

Grab DevBox-Setup-x.y.z-windows-amd64.exe from the latest release. A portable zip is there too. Checksums are in SHA256SUMS-windows.txt.

Son sürümden DevBox-Setup-x.y.z-windows-amd64.exe dosyasını indirin. Taşınabilir zip de orada. Sağlama toplamları SHA256SUMS-windows.txt içinde.

If SmartScreen appears, choose “More info → Run anyway”

SmartScreen çıkarsa “Daha fazla bilgi → Yine de çalıştır” seçin

DevBox is a young open-source project without a paid code-signing certificate yet, so Windows may show “Windows protected your PC”. Every build is produced by a public GitHub Actions workflow from the source you can read; verify the SHA-256 if you like. This warning disappears as the app builds reputation and once signing is in place.

DevBox henüz ücretli bir kod imzalama sertifikası olmayan genç bir açık kaynak projesi; bu yüzden Windows “Windows bilgisayarınızı korudu” uyarısı gösterebilir. Her yapı, okuyabileceğiniz kaynak koddan herkese açık bir GitHub Actions iş akışıyla üretilir; isterseniz SHA-256'yı doğrulayın. Uygulama itibar kazandıkça ve imzalama devreye girdikçe bu uyarı kaybolur.

Run the installer

Kurulumu çalıştır

DevBox installs per user, adds a Start-menu entry, and keeps all data in C:\DevBox. Updates are offered inside the app and install in place.

DevBox kullanıcı bazında kurulur, Başlat menüsüne eklenir, tüm veriyi C:\DevBox altında tutar. Güncellemeler uygulama içinde sunulur ve yerinde kurulur.

Five-minute guide

Beş dakikalık kılavuz

Install a runtime

Bir çalışma zamanı kur

Runtimes → pick PHP 8.4 (or Node, Go…) → Install. The first version becomes global: it's on your PATH, it powers FastCGI, and projects use it unless pinned.

Çalışma Zamanları → PHP 8.4 (veya Node, Go…) seç → Kur. İlk sürüm global olur: PATH'inizdedir, FastCGI'yi çalıştırır, sabitlenmedikçe projeler onu kullanır.

Install a web server and a database

Web sunucu ve veritabanı kur

Services → Web Server → Nginx → Install. Same for PostgreSQL or MySQL. Turn on AUTO so they start with DevBox.

Servisler → Web Sunucu → Nginx → Kur. PostgreSQL veya MySQL için de aynı. DevBox ile başlasınlar diye OTO'yu açın.

Enable the front-door

Ön kapıyı etkinleştir

Overview → Front-door → Install → Start. It listens on ports 80 and 443 and routes *.test to the right backend with HTTPS, so you never type a port again. Projects that run their own dev server bring it up automatically.

Genel Bakış → Front-door → Kur → Başlat. 80 ve 443 portlarını dinler, *.test isteklerini HTTPS ile doğru arka uca yönlendirir; bir daha port yazmazsınız. Kendi dev sunucusunu çalıştıran projeler onu otomatik açar.

Add a project

Proje ekle

Projects → Add → existing folder, template, or Git URL. DevBox detects the framework, registers myapp.test in your hosts file (one UAC prompt) and issues the certificate. Click the domain to open https://myapp.test.

Projeler → Ekle → mevcut klasör, şablon veya Git URL'si. DevBox framework'ü algılar, myapp.test'i hosts dosyasına kaydeder (bir UAC onayı) ve sertifikayı üretir. Alan adına tıklayıp https://myapp.test'i açın.

Share it

Paylaş

Click the share icon for a public *.trycloudflare.com URL. For your own domain: Settings → Cloudflare, paste an API token, pick the zone, then set a public hostname in the project's settings.

Paylaş simgesine tıklayın, genel bir *.trycloudflare.com URL'si alın. Kendi alan adınız için: Ayarlar → Cloudflare, API token yapıştırın, alan adını seçin, sonra proje ayarlarında genel alan adını girin.

Tip: right-click the tray icon for Start all / Stop all / Quit. Closing the window keeps everything running. İpucu: tepsi simgesine sağ tıklayın: Tümünü başlat / Tümünü durdur / Çık. Pencereyi kapatmak her şeyi çalışır halde bırakır.

Share on your own domain with Cloudflare

Cloudflare ile kendi alan adında paylaş

Quick tunnels need nothing — one click gives you a random *.trycloudflare.com link. For a permanent app.yourdomain.com you link a Cloudflare account once. Free plan is enough; your domain must use Cloudflare DNS.

Hızlı tüneller için hiçbir şey gerekmez — tek tıkla rastgele bir *.trycloudflare.com bağlantısı alırsınız. Kalıcı bir uygulama.alanadiniz.com için Cloudflare hesabınızı bir kez bağlarsınız. Ücretsiz plan yeterlidir; alan adınızın DNS'i Cloudflare'de olmalıdır.

Create an API token

API token oluştur

Go to dash.cloudflare.com → My Profile → API Tokens → Create Token → Create Custom Token. Give it a name like DevBox.

dash.cloudflare.com → My Profile → API Tokens → Create Token → Create Custom Token. Adını DevBox gibi verin.

Under Zone Resources pick Specific zone → your domain (or All zones). Leave IP filtering and TTL as they are, click Continue to summary → Create Token, then copy the token — Cloudflare shows it only once.

Zone Resources altında Specific zone → alan adınız (veya All zones) seçin. IP filtresi ve TTL'i olduğu gibi bırakın, Continue to summary → Create Token deyin ve token'ı kopyalayın — Cloudflare bunu yalnızca bir kez gösterir.

Link it in DevBox

DevBox'a bağla

Settings → Cloudflare — custom domain tunnels → paste the token → Verify. Pick the account and the domain (zone) from the lists → Link account. DevBox creates one tunnel for this computer (devbox-<pc-name>) in your account; nothing else changes yet.

Ayarlar → Cloudflare — özel alan adı tünelleri → token'ı yapıştırın → Doğrula. Listeden hesabı ve alan adını (zone) seçin → Hesabı bağla. DevBox bu bilgisayar için hesabınızda tek bir tünel oluşturur (devbox-<pc-adı>); başka hiçbir şey değişmez.

Give a project a public hostname

Projeye genel alan adı ver

Projects → gear icon on the project → Public hostname → e.g. demo.yourdomain.com → Enter. Now the share icon publishes to that address: DevBox adds the DNS record and the routing rule for you. Stopping the tunnel removes both.

Projeler → projedeki dişli simgesi → Genel alan adı → örn. demo.alanadiniz.com → Enter. Artık paylaş simgesi o adrese yayınlar: DNS kaydını ve yönlendirme kuralını DevBox ekler. Tüneli durdurmak ikisini de kaldırır.

Where is the token stored? Only in C:\DevBox\config.json on your machine; it is sent to api.cloudflare.com and nowhere else. Settings → Unlink removes it and deletes every DNS record DevBox created.Token nerede saklanır? Yalnızca bilgisayarınızdaki C:\DevBox\config.json içinde; yalnızca api.cloudflare.com'a gönderilir. Ayarlar → Bağlantıyı kaldır token'ı siler ve DevBox'ın oluşturduğu tüm DNS kayıtlarını kaldırır.

Why does Windows warn about an “unknown publisher”?

Windows neden “bilinmeyen yayıncı” uyarısı veriyor?

SmartScreen judges files by two things: a code-signing certificate and download reputation. DevBox is a brand-new open-source project — it does not carry a paid certificate yet and has not accumulated reputation, so Windows shows the generic warning. It is not a virus verdict.

SmartScreen bir dosyayı iki şeye göre değerlendirir: kod imzalama sertifikası ve indirme itibarı. DevBox yepyeni bir açık kaynak proje — henüz ücretli bir sertifikası yok ve itibar biriktirmedi; bu yüzden Windows genel uyarıyı gösterir. Bu bir virüs kararı değildir.

Verify what you downloaded

İndirdiğini doğrula

Every release ships SHA256SUMS-windows.txt. In PowerShell: Get-FileHash .\DevBox-Setup-*.exe and compare the hash with the file on the release page. Builds are produced by a public GitHub Actions workflow you can read line by line.

Her sürümde SHA256SUMS-windows.txt bulunur. PowerShell'de Get-FileHash .\DevBox-Setup-*.exe çalıştırın ve sonucu sürüm sayfasındaki dosyayla karşılaştırın. Yapılar, satır satır okuyabileceğiniz herkese açık bir GitHub Actions iş akışıyla üretilir.

Run it anyway (safely)

Yine de çalıştır (güvenle)

On the blue SmartScreen dialog click More info, then Run anyway. You only see this once per download; updates installed from inside DevBox are downloaded straight from GitHub Releases.

Mavi SmartScreen penceresinde Daha fazla bilgi, ardından Yine de çalıştır'a tıklayın. Bunu her indirme için yalnızca bir kez görürsünüz; DevBox içinden kurulan güncellemeler doğrudan GitHub Releases'tan indirilir.

Signing is on the roadmap

İmzalama yol haritasında

The release pipeline already supports Authenticode signing (certificate file or Azure Trusted Signing). As soon as a certificate is in place every build is signed automatically and the warning disappears; reputation then builds with each install.

Sürüm hattı Authenticode imzalamayı zaten destekliyor (sertifika dosyası veya Azure Trusted Signing). Sertifika sağlandığı anda her yapı otomatik imzalanır ve uyarı kaybolur; itibar da her kurulumla birikir.

FAQ

Is it really free?Gerçekten ücretsiz mi?

Yes. MIT licensed, no account, no telemetry, no paid tier. The source is on GitHub.

Evet. MIT lisanslı, hesap yok, telemetri yok, ücretli paket yok. Kaynak kodu GitHub'da.

Where is my data?Verilerim nerede?

Everything — runtimes, service data, configs, logs — lives under C:\DevBox. Uninstalling DevBox leaves that folder alone so you never lose a database by accident.

Her şey — çalışma zamanları, servis verileri, yapılandırmalar, loglar — C:\DevBox altında. DevBox'ı kaldırmak bu klasöre dokunmaz; yanlışlıkla veritabanı kaybetmezsiniz.

Does it need admin rights?Yönetici hakkı gerekiyor mu?

Only for two things, each with a visible UAC prompt: writing .test entries to the hosts file, and (on first start) letting the front-door proxy bind port 80.

Yalnızca iki şey için, her biri görünür bir UAC onayıyla: hosts dosyasına .test kayıtlarını yazmak ve (ilk başlatmada) ön kapı proxy'sinin 80 portuna bağlanması.

Does it conflict with Laragon, XAMPP, Docker?Laragon, XAMPP, Docker ile çakışır mı?

Not by itself — DevBox uses its own folder and its own ports (8503+, 5432, 3306…). If another tool already uses a port, DevBox tells you before installing and lets you pick another.

Kendiliğinden hayır — DevBox kendi klasörünü ve portlarını (8503+, 5432, 3306…) kullanır. Başka bir araç bir portu kullanıyorsa DevBox kurulumdan önce söyler ve başka port seçtirir.

When is macOS coming?macOS ne zaman?

The macOS build compiles today, but the runtime/service download sources for macOS still need validation. It ships as a separate release once it passes the same tests as Windows.

macOS derlemesi bugün çalışıyor; ancak macOS için çalışma zamanı/servis indirme kaynaklarının doğrulanması gerekiyor. Windows ile aynı testleri geçtiğinde ayrı bir sürüm olarak yayınlanacak.
